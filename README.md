# Watershed Babylon — build preview

A compiled preview build of Watershed Babylon, published so it can be opened on a phone or any browser without a local server. **This repository contains no source code**, only the output of a production build.

Current build: `claude/55-belly-transition` at `9f02b2bd4d95edf6e05d11c149d4f20a1747b2b3`, the head of pull request #85 in the private source repository.

## What this build changes

A mend used to assign the rod's working lift outright. The bleed back into the resting carry was modelled; the rise was a step. Measured on an ordinary dry-fly drift, that moved the rod tip 1.3434 m in a single tick, against 0.016 to 0.029 m in every neighbouring tick. The rod-tip-to-fly chord grew 0.88 m in that frame, and the drawn line, correctly conserving its length, gave up 1.2890 m of belly to pay for it. That single frame is the line going from a belly to fully straight with no gradual transition.

The stroke now travels to the same peak and bleeds back on the same curve. The mend keeps its full amplitude and throws the same loop; only the rise takes the roughly 0.2 s an arm actually needs.

| | before | after |
| --- | --- | --- |
| worst rod tip step during a drift | 1.3434 m | 0.1898 m |
| worst bow change during a drift | −1.2890 m | none mid-drift |

## What to look for

Fish a drift and mend it. The rod tip should travel to its lifted posture rather than jumping there, and the belly should give way with it instead of vanishing between two frames.
